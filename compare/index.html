The paperlesspaper app vs spectra6-dotgain

Images dithered for the OpenPaper L (1600×1200) two ways: by epdoptimize 1.3.0 the way the paperlesspaper app runs it, re-created from the app's source, and by spectra6-dotgain. Both are simulated as the panel would show them, with a model measured on a real panel in which darker pixels bleed into lighter neighbours. Our dithering is designed for that model, so it has the advantage here; the README has the tests on a real frame.

The square in each image's bottom-left corner magnifies the small square marked on the image. Drag the marked square, or click anywhere, to move it in all three images of the row. Panel white is shown as screen white. The model's black is a little purple-blue in both simulations.

This page reads its images' pixels, which browsers block for files opened from disk. Open it from a web server instead, for example python3 -m http.server in the repository folder.
